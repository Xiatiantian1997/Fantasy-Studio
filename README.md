# 幻真画室｜Fantasy Studio

**一个软件，三个 GitHub 仓库。**

本仓库是「幻真画室」的**总控项目**：负责软件的统一用户入口、2D/3D 模块协调、素材与作品索引、共享配置、权限和模块间数据接口。

> **当前状态：总体架构框架已建立；尚未开发可运行的总控启动器。** 现有 2D 生图代码保留在 2D 仓库，可以独立开发和验证；3D 仍处于建模与导出接口准备阶段。不要把文档或规划当成已经实现的软件。

## 三个仓库的分工

| 仓库 | 负责 | 不负责 |
| --- | --- | --- |
| **[Fantasy-Studio](https://github.com/Xiatiantian1997/Fantasy-Studio)（本仓库）** | 总体规划、统一界面、启动/编排、共享素材索引、作品历史、2D⇄3D 协议 | 重新实现绘图模型或 Blender |
| **[Fantasy-Studio-2D](https://github.com/Xiatiantian1997/Fantasy-Studio-2D)** | ComfyUI 生图、三种绘画风格、图生图/参考控制、局部修改 | 3D 网格、骨骼与真实模型形变 |
| **[Fantasy-Studio-3D](https://github.com/Xiatiantian1997/Fantasy-Studio-3D)** | 成年人体基模、Rig、姿势、相机、深度/法线/姿态控制图 | 最终 2D 画风与作品管理 |

原有 [body](https://github.com/Xiatiantian1997/body) 是**独立人脸研究库**，保留原样，不算第四个软件模块。原有科学 2D/3D 交互项目也不纳入本产品。

**一个用户入口**指最终统一软件体验，不意味着现在就强行搬移正在开发或运行的 2D 代码。

## 用户最终如何使用

打开「幻真画室」后，只看到四个清楚入口：

1. **2D 绘画**：选择人物、画风、姿势与参考图，生成、修图。
2. **3D 人体**：选择成年人体基模、姿势、镜头，导出结构参考。
3. **素材库**：按脸、姿势、服装、材质、画风搜索；保留来源和访问权限。
4. **作品**：保存图片、角色、参数配方、版本与对照结果。

后台交给 ComfyUI、Blender 和本地模块完成；用户无需理解节点连线、权重涂抹和专业三维操作。

## 约定：三个仓库独立做，但能接起来

```text
           幻真画室总控（本仓库）
            ├─ UI / 配方 / 素材 / 历史
            ├─ 调用 2D 模块（本地 API）
            └─ 调用 3D 模块（起初通过文件交换）
                         |
                3D: 模型 + 姿势 + 相机
                         |
       manifest.json + RGB + Depth + Normal + Pose
                         |
                         v
                2D: ControlNet/参考控制
                         |
                         v
                三种 2D 画风生成结果
```

**先保持宽松耦合**。3D 输出必须符合 3D 仓库的 [interface-v0.1.md](https://github.com/Xiatiantian1997/Fantasy-Studio-3D/blob/main/docs/interface-v0.1.md)，本总控只定义调用顺序、模块状态和共享索引，不复制一份矛盾的导出格式。

## 已确认的产品方向

- 当前画风主线：**幻真动漫、半写实插画、数字油画**；真人写真作为后续可选模式。
- 3D 长期目标：**通用可调的成年人体母版**，先五种稳定姿势，再体型、换装、角色一致性；不做内脏或复杂实时肌肉物理。
- 操作：AI 辅助与用户手动共用本地软件，**不同访问权限而不是两套数据或两个版本**。
- 存储：Windows 优先，RTX 3060 Ti 8GB；大型文件尽可能在非 C 盘，GitHub 不放私人原图和模型权重。
- 职业与兴趣分开：这是私人数字美术兴趣项目，不为商业交付增加不必要复杂度。
