# 幻真画室｜Fantasy Studio

一套本地角色创作画室，兼顾 **2D 精美出图**与 **3D 模特欣赏、搭配、取景**。两者可以独立使用，也可通过结构参考连接。

**当前是文档规划与部分开发代码阶段，尚未形成完整可用的软件。** 本轮汇总更新于 2026-11-11，只更新文档；没有完成本机安装、GPU 生成、模型适配或界面验收。

## 当前方案

- **房间即界面**：模特、双开门衣柜、摄影机、书柜为四个实体入口；微缩房间导航带动镜头平滑切换。
- **同一模特持续存在**：人物、身材、姿势、衣装和表情在切换功能时保留；观察相机与写真相机分别保存。
- **独立观察**：隐藏房间和工具，只看模特；互动关闭时单击衣件临时隐藏，退出恢复原搭配；可选身体互动仍待验证。
- **衣装先做简单搭配**：三种固定基础身材、固定姿势、三维成衣保存；精细纹样、蕾丝和最终修图交给 2D。
- **书柜收藏作品**：生成图按相册归档，支持封面、翻看、收藏和继续修改；有完整 3D 快照时可恢复取景。
- **八类元素可复用**：人物、身材、姿势、衣装、表情、镜头、场景、画风分别保存与组合。
- **2D 主线画风**：幻真动漫、半写实插画、数字油画；真人写真为后续可选方向。
- **长期能力另列**：连续体型编辑、动作积木、2D 微动画与软组织实验保留，但不是近期换装的前置条件。

## 一个软件，三个技术仓库

| 仓库 | 职责 |
| --- | --- |
| [总控](https://github.com/Xiatiantian1997/Fantasy-Studio) | 统一界面、启动编排、素材与作品索引、共享配置 |
| [2D](https://github.com/Xiatiantian1997/Fantasy-Studio-2D) | ComfyUI 生成、风格配方、参考控制与图像修改 |
| [3D](https://github.com/Xiatiantian1997/Fantasy-Studio-3D) | 人体、骨架、姿势、相机、形变及结构图导出 |

[body](https://github.com/Xiatiantian1997/body) 是独立人脸研究库，不是第四个产品模块；科学交互项目也不并入画室。自建界面、索引与连接代码，复用 ComfyUI、Blender 等成熟工具，不重新开发完整绘图模型或建模内核。

## 实际进展

- **总控**：文档、配置示例和旧静态界面原型；没有可运行的统一启动器。
- **2D**：已有服务、安装/启动脚本、基础文生图、整图图生图及单 LoRA 工作流代码；用户 RTX 3060 Ti 实机验收未完成。
- **3D**：已有方案、导出格式、示例与校验脚本；没有验收通过的完整人体、真实导出和 ControlNet 联动。
- **最新房间界面与自动换装**：尚未实现。[旧 HTML 原型](prototypes/studio-shell.html) 仅保留作历史参考，不代表当前 UI。

性能目标是在 RTX 3060 Ti 8GB 上尽量于 2–5 分钟内生成一张精美插画，尚待实测。Windows 项目、大模型和素材优先放非 C 盘；GitHub 保存代码与文档，不保存私人原图或模型权重。
