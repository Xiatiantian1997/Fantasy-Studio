# 作品相册｜书柜与归档

更新：2026-11-11。已确认的产品方案，**尚未实现界面、数据库或保存恢复功能**。房间导航见[产品体验](product-ux.md)，实施阶段见[开发状态](roadmap.md)。

## 定位

书柜是房间里的作品入口，收纳生成图片；衣柜继续负责服装搭配。相册复用总控的作品历史和索引，不建设重复图库，不增加八类输入元素的类别。2D 可独立使用相册，无需启动 3D。

## 首版体验

- **归档**：生成结果保存时选择已有相册或新建；不选择就进入“未整理”。相册按人物、主题、系列自由命名，不强制多层目录。
- **封面**：默认使用首张作品，允许选另一张作为封面；名称简短，可改名。
- **浏览**：点书柜查看封面列表，点相册看图片；支持左右翻看、缩放和收藏。缩放状态的拖动用于平移图片，避免误切下一张。
- **整理**：支持单张或批量移到其他相册。首版一张作品归属一个相册，收藏是独立标记；以后需要多相册引用再扩展。
- **继续修改**：将选中图片送回 2D 修改入口，新结果另存版本，保留原图；实际可用编辑能力以 2D 模块实现为准。
- **恢复取景**：只有关联完整 3D 快照且依赖可用的作品才可恢复；普通 2D 图不显示可恢复的承诺。

房间书柜只承担视觉入口。管理用适合手机的封面列表和多选操作，首版不做真实抽书、逐页网格变形或复杂 3D 翻书。切换书柜不会重置模特和写真相机；打开旧图仅浏览，明确点击恢复才加载旧场景。

## 保存规则

| 对象 | 保存内容 |
| --- | --- |
| 相册 | 稳定 ID、名称、封面作品引用、作品排序 |
| 作品 | 稳定 ID、原图路径、缩略图、所属相册、收藏标记、生成时间与来源 |
| 修改版本 | 新作品 ID、父版本引用；不覆盖原图 |
| 生成信息 | 能取得时记录提示词、种子、工作流、模型与版本；缺失字段如实标注 |
| 可选 3D 快照 | 人物/母版与资源版本、体型、姿势、表情、衣装、写真相机、场景和必要形变状态 |

原图只保存一份；移动相册和修改封面更新引用，不复制高清原图或重新压缩。列表加载缩略图，打开单图再读原图，避免大量图片同时占用内存。封面作品移出时自动改用该相册首图，空相册显示占位封面。

恢复依赖资产路径与版本有效。缺失时保留作品浏览和 2D 修改入口，说明无法恢复的项目，不能用猜测的模型或视角冒充原取景。恢复前保留当前未保存的创作状态，允许返回。即使生成信息齐全，也不承诺不同环境重新生成完全相同的像素。

作品原图保存在用户本地作品目录，默认随项目配置放非 C 盘；GitHub 仅维护代码、文档和必要示例，不保存私人作品全集。

## 验收与难度

基础归档和浏览属于常规图片管理，难度相对低；完整创作状态恢复依赖 2D/3D 接口、资源版本与持久化，单独验收。

1. 保存图片到新建/已有相册，不选择时进入未整理。
2. 改名、换封面、收藏、批量移动后，重启仍保留正确结果，原图未被重复复制。
3. 手机上可清楚选择相册、翻看和缩放；进入退出书柜不改变当前模特与写真取景。
4. 修改生成新版本，原图与来源关系保留。
5. 有完整快照的作品恢复原取景；缺失快照或资产时明确提示，不假装恢复成功。

书柜视觉原型可先用样例图片验证。真实生成归档在总控接入 2D 后实现；3D 恢复在真实状态保存接口可用后接入。没有实测前不标记完成。
