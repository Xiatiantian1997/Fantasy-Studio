## 实施顺序

| 阶段 | 工作 | 验收结果 |
| --- | --- | --- |
| 1：2D 基线 | 保留现有入口，在用户 Windows 上运行文生图、图生图和保存 | RTX 3060 Ti 实际出图；记录耗时、显存、画质和失败 |
| 2：总控接入 | 接管启动与基础任务状态，逐步连接现有 2D 服务 | 一个入口可生成、查看、停止；旧路径可回归 |
| 3：3D 基线 | 选用/适配现有授权母版，验证骨架、五姿势、真实相机 | 可旋转，明显穿模受控；姿势和镜头可保存复现 |
| 4：结构闭环 | 同帧同机位输出 RGB/Depth/Normal/Pose，由 2D 适配控制工作流 | 换姿势/机位可引导成图，参数与输出可追溯 |
| 5：日常创作 | 完善房间体验、元素索引、书柜相册、三画风与局部修改 | 可生成归档、翻看、收藏、移动和继续修改；有完整快照时恢复取景 |
| 6：衣装小模块 | 先一件成衣，扩展到三身材与少量固定姿势 | 可导入、搭配、旋转查看、保存并恢复 |
| 后续可选 | 动画、连续体型扩展、图片转衣装、打包更新 | 逐项实测后才纳入稳定功能 |

一间房/一位模特/衣柜/摄影机/书柜的**界面原型验证可以单独进行**，书柜可先用样例图片验证浏览；但不能用界面演示代替数据库持久化和上述实机验收。姿势与相机是闭环必需项；3D 同时保留独立欣赏用途，2D 不被强制依赖 3D。

## 范围约束

- 衣装阶段不要求实时布料、任意体型、裁片编辑或动画；固定姿势降低适配范围，但新成衣仍可能需要修形。
- 书柜首版复用作品历史，只做封面、归档和图片浏览，不做复杂 3D 翻书。详细边界见[作品相册](albums.md)。
- 动作捕捉暂缓；当前身体表现限轻微形变、回弹和次级运动。床、泳池与大幅动作留待后续家具升级再评估。
- 连续体型、动作积木、2D 微动画与软组织测试作为长期专题保留，不提高近期衣装验收门槛。
- 先验现有模型、骨架、权重、形态键与来源，再补缺口；不先囤大量姿势包或安装多套插件。
- 优先使用成熟工具，画室负责易用界面、索引和连接。格式相同不保证骨架、材质或动作兼容。
- 非 C 盘优先；接口升级应保留版本信息、备份和失败回退。打包不是先于功能验证的任务。

身体表现可在合格母版上单独做小实验，不改变主线实施顺序；轻量次级运动、有限按压和兼容衣件逐项验收，见[身体互动可行性](body-interaction.md)。百度云资源尚待补充，当前样本不能代表全部素材。
