## 这轮的范围决定

1. **相机不是锦上添花。** 3D 不仅供自由旋转看模型，还必须有独立可保存的最终摄影机位；姿势、相机、画幅共同决定发给 2D 的结构图。
2. **3D 不追求照片级成片。** 核心是固定人物/简化白模、姿势、透视和基本轮廓；最终衣服、光影与艺术细节给 2D。简化的软组织修形按实际视觉问题添加。
3. **服装设计已记录，但先不实施。** 不因为视频里有 MD/AI 打版就立刻安装和开发。先有可操作姿势与相机，再考虑服装小模块。
4. **不同格式要验证。** 不是所有姿势线稿都能自动还原成准确 3D；不是所有 .fbx 都有可用 Rig；图片解析也不等于生成真实服装纸样。
5. **保留已写代码与来源。** 不删除 2D 现有启动器和工作流；大模型、摄影参考和素材原档存本地非 C 盘，GitHub 不存私人原图或权重。

## 下一项实测

先在用户 Windows 上把现有 2D 生成跑通；3D 独立使用真实基础模型验证姿势，优先打通 **相机取景 → RGB/Depth/Pose 输出 → 2D 生成**。直到闭环通过，再考虑服装与更复杂物理。
