## 防止工程返工

- 保留 2D 仓库已经写好的安装脚本/HTML/API，直到总控迁移验收通过后再考虑删除或精简。不要重新编写同等的 ComfyUI 功能。
- 3D 在 Blender 里先解决形变，别先做复杂网页查看器。
- 3D 导出以 3D 仓库为唯一协议来源；总控不重新定义 Depth/Normal 标准。
- 大文件、模特、成人原档、第三方 ZIP 留在非 C 盘私人工作目录。
- 每个阶段要有可复核测试记录，不“凭代码写好了”就宣布已完成。

## 你在家要做的第一件事

把本地资料和代码放到非 C 盘，保留备份；先在 Windows 上启动现有 2D 工作流实际出一张测试图，确保 ComfyUI 工作正常。随后才正式开发总控启动器和 3D 集成。
