# 幻真画室｜AI 协作与内容边界

> 2026-11-09。供用户、ChatGPT 与 Grok 沟通项目分工；属于协作约定，不是对任何服务未来政策、能力或授权的保证。未经用户明确同意，不自动将私人素材发送到第三方 API。

## 共同目标
幻真画室是个人 Windows 本地的 2D/3D 角色创作工具。核心：精美角色插画、连续人体网格与可旋转 3D 观察、姿势与体型预设、服装配饰、骨骼/网格形变、程序化动画、作品保存。程序架构和通用能力不因内容风格而分叉；优先在本地处理私密素材。

## ChatGPT 负责（主开发与验收）
- 三仓库架构、Windows 安装、UI、Blender/Three.js/ComfyUI 联动、模型和动作资源索引、通用姿势/碰撞/IK/材质/渲染/动画系统、Spine 技术研究、性能优化、版本升级与回退。
- 成年人体解剖、白模、体型参数、一般裸体人体研究；普通服饰、泳装、内衣、项圈等装饰性配饰；非露骨的人物造型、单人或双人互动动作。
- 胸臀等软组织的中性技术研究：局部骨骼、网格权重、形态键、惯性、弹簧阻尼、接触与碰撞，避免把通用算法误称为特定色情动作。
- 通用的文件导入、动画预览、GIF/MP4 导出、私有素材分类及可复用 API。明确区分“代码功能可实现”与“某项具体内容可由当前服务生成”。
- 不负责生成露骨性行为或色情画面/视频；不以写提示词、分镜或专用工作流等方式绕过当前服务内容边界。

## Grok 或其他服务的职责（需单独确认其规则）
- 用户可自行在其服务允许的范围内进行更成人化的私人创作、内容审查和风格实验；不预设 Grok 一定允许任何具体请求。
- 用户若从外部获得合法使用的素材，可按本地软件支持的通用格式导入幻真画室。ChatGPT 不需要直接生成、审阅或处理不适合其能力边界的露骨内容。
- 任何外部服务不得默认读取整个私人素材库；仅用户明确选择的文件可发送，记录来源、用途和授权。

## 具体内容分类（按表现方式判断，不是机械关键词过滤）
A. 通常可协助：成年人体白模、解剖研究、非性化裸体形态、身材/表情/皮肤/姿势、服装配饰、非露骨单人或双人动作。
B. 需看具体场景：乳夹等身体配饰的尺寸/材质/结构研究、项圈与牵引动作、成人主题角色造型、局部接触与形变；可做中性技术和非露骨呈现，不保证所有具体生成请求均可处理。
C. 不由 ChatGPT 生成：明确性行为、露骨性接触、以色情刺激为目的的具体画面/动画/分镜。不得以“只是代码”作为绕过边界的理由。
D. 未成年人或年龄不明且呈现为未成年者，不用于成人性内容；仅使用明确成年角色进行成人主题研究。

## 技术接口与文件边界
- 主程序统一维护人物、体型、姿势、镜头、衣装、动画规则等中性数据结构；不把第三方生成模型或内容政策硬编码成唯一流程。
- 本地模块通过版本化 JSON/文件接口或 localhost API 交换模型、动作和渲染参数。AI 模型 API 只在用户授权时调用；Codex/Work 是开发工具，不是播放每帧动画的依赖。
- 外部工具生成的图片/视频由用户决定是否导入；不自动同步第三方账户、云端图库或成人原始素材。
- 原始压缩包只读，私有素材留在本地 D 盘，GitHub 仅存程序、说明和许可允许的小样。

## 跨助手沟通模板
项目：幻真画室（Fantasy Studio）。
现状：三主仓库 + 独立 spine 研究仓库；大部分功能仍在设计/原型阶段。
ChatGPT 负责：程序设计、开发、调试、通用 2D/3D/动画技术与非露骨内容。
Grok 负责：用户选择交给它且符合其自身规则的成人主题内容；不得假设其规则或访问权限。
共同接口：用户提供的图像/视频/模型文件、通用姿势与动作预设、版本化 JSON。未经授权不跨服务传输私人素材。
协作原则：先描述可验证的输出、输入格式和质量要求；区分已实现与规划中；不共享未经许可的游戏/付费素材；不以技术分工绕过任何服务规则。
