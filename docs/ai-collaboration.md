# 幻真画室｜协作与素材管理

本文件描述多个 AI 工具共同参与幻真画室开发时的职责与接口。所有工具须遵循各自服务规则，具体内容制作由用户自行选择适用的服务。

## 角色分工
- ChatGPT：主程序架构、2D/3D 工作流、通用人体建模、姿势/骨骼/IK、局部形态键、网格形变、材质、动画、导入导出、测试及文档维护。
- Grok 或其他工具：在其自身能力、授权及内容规则允许的范围内提供素材和创意参考；不预设对方支持任何特定内容。
- 用户：决定素材来源、保存位置、授权范围与对外分享内容。

## 统一技术接口
- 通过版本化 JSON、模型文件、动作预设和本地 API 交换数据；不要求所有工具共享账户或文件系统。
- 支持角色、体型、姿势、镜头、服装、配饰、形态键与动画参数的独立预设。
- 外部导入的文件保留来源、许可、适用骨架、版本与预览状态；未经用户确认不发送给第三方服务。

## 公开与私人资料
- 公开仓库只存通用代码、文档和有再分发许可的示例素材。
- 用户私人素材与配置默认留在本地独立目录，不提交 GitHub；不出现在软件首页、公共示例、日志或搜索结果中。
- 不将“目录隐藏”视作权限保护；需要真正保密时应使用本地访问控制、排除规则和备份策略。
- 不在公开文档列举私人素材细节。公开仓库提交历史可被查看；此前已提交的内容不能仅靠改写当前文件保证不可见。
