# 幻真画室｜单一界面设计

**原则：简约而不简单。** 技术分三个 GitHub 仓库，用户永远只有一个软件入口。当前只定义产品体验，不代表统一桌面 UI 已完成。

## 四个主入口

1. **2D 绘画**：画风（幻真动漫、半写实插画、数字油画）、人物、姿势、描述、生成结果与重绘。
2. **3D 人体**：默认显示有体积的正常人体表面；选体型、选姿势、旋转/缩放、切角度、送入 2D。骨骼/线框仅为可选检查模式。
3. **素材库**：检索人脸、人体结构、姿势、服装、材质、画风；浏览来源与个人收藏。
4. **作品**：作品历史、图像参数、角色身份、衣服、姿势、种子、风格配方与版本。

**不显示 ComfyUI 节点连线，也不让用户为了画图先学 Blender。**

## 两种使用方式而非两个软件版本

- **AI 辅助**：用户讲目标，AI 通过获授权的受限控制接口运行和复核，不能直接访问私人全集。
- **手动专业操作**：用户可以打开更多参数、自选模型和文件，仍由本地软件执行必要的安全和文件保护。

两种方式都在一个应用中切换，底层共享模型目录、作品索引和选定的通用素材，不重复建两套系统。

## 画风体验

用户选画风不等于模型就自动改变艺术语言。每个稳定预设要绑定实际基础模型/LoRA、参数和参考策略，使用同一人物对照验证。三种画风优先，真人摄影仅是后续可选。

## 3D 人体体验

将来用户可以有一个可调的成年女性通用基模，预设站姿、侧身、坐姿、举手、跪姿；体型调整和服装换装逐步增加。初期在 Blender 验证 Rig 与姿势，之后总控再提供简化 UI。

## 进展显示

每个功能必须标记真实状态：**已实现、已通过本机测试、规划中、当前不可用**。不要把单独 HTML 演示或静态人物图当成真正 3D 交互。

用户最终安装时只用一个启动器；过渡期 2D 的旧开发启动器暂保留，不视为第二个对外版本。
