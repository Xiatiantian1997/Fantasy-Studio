# 产品体验｜房间式画室

更新：2026-11-11。本文汇总已确认的体验方向，**尚未实现或验收**；待定交互另列。当前导航采用房间与家具，不再采用早期四入口面板或三状态标签页。

## 目标与使用方式

画室有两个并列用途：生成精美 2D 角色插画，以及独立欣赏、旋转和操作成年女性 3D 模特。2D 可直接使用参考图出图，不强制先启动 3D；需要真实姿势、遮挡和透视时再从 3D 取景。

用户通过自然中文、预设、拖动与少量必要控件操作；AI 把意图转换为实际工作流。不让用户学习 ComfyUI 节点、骨骼权重或专业摄影面板。高级编辑按需进入，不堆在主界面。

## 房间与三个入口

主界面是一间华丽但克制、柔和私密的写真工作室。起步只放一位模特、一只大衣柜、一台摄影机。地面考虑香槟/象牙色短绒丝绒地毯或软垫，使站、坐、跪、躺都自然；颜色、材质与接触效果待视觉验证。

| 实体入口 | 进入后的体验 | 常用元素 |
| --- | --- | --- |
| 模特 | 镜头聚焦人物，观察并进入姿势、身材或表情调整 | 人物、身材、姿势、表情 |
| 衣柜 | 模特和衣柜同时可见，点选衣件或套装预览搭配 | 衣装、配饰 |
| 摄影机 | 进入真实相机取景，拍照/生成并查看 2D 结果 | 镜头、场景、画风；可调用姿势与表情 |

八类元素是可组合的操作对象，不是八个顶级页面；其保存规则见[元素与素材](element-library.md)。素材搜索和作品历史可使用普通列表，不必把所有管理界面做成家具，也不引入游戏任务、抽卡或等级系统。

房间、衣柜、摄影机和地毯的外观可用 AI 生成素材替换，功能入口保持不变。需要旋转、遮挡或点击的部分应保留必要空间结构；单张外观图不等于任意角度可看的真实 3D。

## 导航与状态连续

- 普通功能界面保留低存在感的**微缩房间导航**。点击模特、衣柜、摄影机或房间整体，主镜头平滑移动至对应预设机位；可直接跨功能切换。
- 预设机位只决定进入时的构图，不锁死后续视角。小屏可收起/展开导航；具体位置与尺寸待验证。
- 始终使用同一模特与作品状态，切换时不重置人物、体型、姿势、表情和穿搭。
- **观察相机与写真相机分开保存**；转场不覆盖最终取景。离开普通功能后是否恢复上次观察角度，尚待验证。
- 模特在布局中变大或缩小通过视口和相机实现，不改变真实体型。过渡柔和但应短促，不妨碍连续操作。

## 模特操作与独立观察

普通人物功能中，观察和编辑分开：环绕、缩放不改模型；明确进入编辑后才调整姿势、体型或表情。姿势预设独立于体型与镜头保存。默认正常基础皮肤材质，白模、轮廓和骨架只作检查选项。

**独立观察是单独的极简查看状态，不是完整编辑器：**

- 隐藏房间、家具、地面/地毯、微缩导航和素材卡，仅保留模特、柔和纯色或渐变背景，以及清楚的退出按钮。
- 可旋转与缩放。**单击可见衣件直接临时隐藏**，允许连续隐藏多件，隐藏后提供极简恢复入口。
- 隐藏不删除衣件、不修改保存的搭配；退出时恢复衣装和进入前的房间上下文。
- 修改姿势、体型、表情或换装时，退出后进入相应功能。

鼠标左拖旋转、滚轮缩放、右拖平移，以及双击部位聚焦/双击空白恢复全身属于候选交互。触屏手势、双击与单击隐藏的冲突、多层薄纱的命中方式尚待实测；这些不能当成已确认且可用的操作。

## 衣柜

已确认采用双开门外观，内部用精美画册/图片陈列，不要求真实逐件从衣架取下。

- **左柜：单件，按种类**，如上衣、裙装、袜饰、配件。
- **右柜：套装，按风格**，如宫廷、礼服、日常、幻想。
- 模特保持可见、可旋转；选衣件后预览，选整套后仍可替换其中单件并保存新搭配。
- 搜索入口低存在感，按名称、材质、颜色或风格查找；分类随资源量调整，避免密集方格和多层菜单。
- 左右柜是内容分区，不要求小屏机械各占一半。衣柜外观和服装图片可独立替换。

近期执行范围统一采用[衣装方案](clothing-plan.md)：三种固定基础身材、固定姿势、三维成衣与简单搭配，不做实时布料、任意体型自动适配或手工裁片编辑。新衣服入库的修正由后台处理，用户无需刷权重或反复微调。

## 摄影与 2D 创作

进入摄影机后保留当前模特状态，用真实虚拟相机取景。主控件以**取景、拍照/生成、查看结果**为主；画幅优先竖/方/横，其他设置按需展开。

1. 拖动、旋转、缩放调整构图，可选常用机位并保存自定义镜头。
2. 拍照形成当前姿势与真实相机的结构参考，交给 2D 工作流。
3. 在摄影界面查看结果，保存、重拍或用自然语言提出局部修改。
4. 保留原 3D 状态、原始渲染与各版生成图，支持比较、恢复和返回取景。

底层保留机位、角度、投影、焦距/视角、画幅等可复现参数；不要求用户理解矩阵或大量摄影术语。可锁姿势调相机，也可锁相机调姿势。不同结构图须同姿势、同机位、同分辨率；技术格式见[协作接口](integration.md)。

本地 ComfyUI 是主要生成路径；ChatGPT 生图是能力和规则允许时的辅助路径，不能假定独立软件可直接调用聊天中的生成工具。自动切换方式、可用 API 和构图一致性均未验证。AI 猜测新视角也不能替代真实 3D 相机。

画风主线为幻真动漫、半写实插画、数字油画；真人写真后续可选。最终审美以用户认可的参考图为准，检查人物、透视、礼服、皮肤与布料光影。保留人物身份与姿势的局部换衣/修脸/换背景是目标，尚不承诺精确不漂移。

## 长期能力与近期边界

- **体型**：长期采用一个验证过的连续人体母版、三档快捷预设及局部连续微调；联动、修正和有效范围见元素文档。近期衣装只承诺固定三身材的已验证组合。
- **姿势与动画**：姿势先精选与适配；动作积木、插值、次级运动见[动画研究](animation-roadmap.md)。衣装当前“不做动画”不代表取消整个产品的动画方向。
- **2D 微动画**：未来尝试分层、补画遮挡、网格绑定及眨眼/呼吸/发丝等循环。静态图不天然带骨骼，失败应可回退静帧。
- **衣服图转 3D**：保留“导入图片 → AI 分析/修改预览 → 用户确认 → 尝试简化成衣”的未来候选。不要求用户手工打版，不合适时可更换参考或仅用于 2D；多视角设定中的背面是推测，不能当作真实裁片或自动可穿戴网格。不纳入近期成衣搭配验收。

## 仍需验证

| 问题 | 验证重点 |
| --- | --- |
| 房间导航 | 小屏命中、遮挡、转场速度、视角恢复 |
| 模特入口 | 观察、部位选择、编辑、独立观察之间不误触 |
| 衣柜 | 模特与图片分类同时可见，多层衣件点击准确 |
| 摄影结果 | 取景图、成图、局部修改和返回 3D 的连续体验 |
| 空间表现 | 地毯接触、阴影、躺卧姿势与轻量环境协调 |
| 性能 | 实际模型预览及生成资源占用，不能仅凭概念图判断 |

第一轮界面验证只需一间房、一位模特、一只衣柜、一台摄影机，演示导航与返回；不扩展新家具。实际工程顺序与完成状态集中见[开发状态](roadmap.md)。
