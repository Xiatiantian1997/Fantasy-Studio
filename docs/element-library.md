# 元素与素材｜保存和复用

更新：2026-11-11。当前产品设计，尚未实现自动解析、素材数据库或真实跨模型复用。技术候选与参考/训练策略另见[素材技术](element-library-notes.md)。

## 作品组与元素卡

一级是**作品组**，关联一张或多张原始参考图；二级是可独立保存、组合的**元素卡**。八类不等于八张卡，也不是八个顶级页面。同类可有多张卡，同一资源可引用多张图。

资源卡不等于裁切 PNG：它可以引用原图、裁切范围、缩略图、文字、参数、蒙版、骨架或 3D 资产。共享原文件，不为每张卡重复复制高清素材。原图只读，派生结果另存并可追溯。

明确区分：原图可见信息、AI 识别/估计、AI 推测补全、用户确认、实际测试通过。单图无法唯一恢复隐藏身体、衣服背面、关节深度或真实镜头参数。

## 八类元素

| 类别 | 保存与使用规则 |
| --- | --- |
| **C 人物** | 脸与发型作为整体身份，包含发色、眼睛、耳朵等稳定特征；默认一起应用。可后续修改并另存版本，不要求预先拆散 |
| **B 身材** | 保存完整体型参数快照、母版/骨架版本与兼容信息；界面是一张简洁身材卡，标准姿势下展示正面、侧面 |
| **P 姿势** | 保存参考、姿态/骨架引用与必要预览；与人物、身材、镜头分离，不为每个姿势复制整个人体 |
| **O 衣装** | 整套为主卡，衣件/配饰可作为被引用部件；同款正侧背参考归同一卡，不覆盖原搭配 |
| **E 表情** | 保存面部特写、眼眉嘴型/眼神、标签和必要参数；与身份分离，跨人物参考不能连来源人物的五官一起替换 |
| **K 镜头** | 通用相机/取景预设；不同机位分别成卡，可微调另存。真实 3D 参数可精确记录，单张 2D 图只存可靠线索和估计 |
| **G 场景** | 保存环境、物件、前中后景、人物预留位置、光照和场景专属构图；可引用 K，同场景可关联多个视角 |
| **S 画风** | 整体风格为主，关联多图、色板、明暗、线条、边缘和材质光影描述；与人物、衣装结构和场景布局分离 |

动画可作为未来附加资源，规则见[动画研究](animation-roadmap.md)，不强制成为每个作品组的第九张卡。

## 人物与身材细则

人物卡默认展示完整头部，优先正面，条件允许时补充 45°、侧面、后面。可换发饰可随人物展示，但底层按配饰记录。切换人物身份应尽量保留已选身材、姿势、衣装、背景与镜头；跨模型能否做到仍需适配。

身材卡只保存结果，精细调整在独立编辑模式完成，观察/摄影操作不修改体型。模型有可用 Shape Keys（形态键）才能直接连接相应控件；固定网格需先制作或适配形变能力。

长期体型方向：

- **一个经过验证的连续人体母版 + 三档快捷预设 + 局部连续微调**，不要求为每种画风从零建模。
- 胸部变化需协调胸廓、根部、腋下与肩部连接；臀部变化需协调腰臀、骨盆附近与大腿根部。联动有方向与范围，不是全身一起缩放。
- 推荐、扩展、禁止三段范围须按实际母版和组合实测；UI 的 0–100 不能冒充通用物理尺度。
- 使用主形态键、修正形态键及必要的骨骼/蒙皮修正；极端组合允许回退或额外适配。
- 体型保存几何，刚度、阻尼、回弹另存物理/动画配置；丰满不等于柔软。
- 验收覆盖三档体型和典型姿势，检查轮廓、连接过渡、关节与穿模；未经测试的组合仍是候选。

**近期衣装只适配三种固定基础身材**，不能把长期连续微调能力当作现有衣服自动兼容承诺。具体范围见[衣装方案](clothing-plan.md)。

## 姿势、衣装及场景细则

- 姿势先从现有模型与动作精选，少量分类，每类约 2–3 个用户认可的候选；图片估计须可修正。保存、重定向和接触修正见[姿势研究](pose-feasibility.md)。
- 衣装默认用正常成年女性体型、基础皮肤质感的标准模特预览。主体、薄纱、袖子、裙摆、饰品按实际搭配价值拆分，不强制全自动细拆。
- 衣装多视角共享一张卡，部件可被其他套装引用。原图、必要蒙版/透明层、属性、来源、预览与可选 3D 数据分别关联；推测背面不得标成原图提取。
- 人物遮挡的背景只记录可见部分，补全另存；相似场景不自动当同一场景合并。
- 画风卡可引用不同图片贡献的视觉特征，不必每图一张卡；自动描述不是原作者精确绘画参数。

## 使用与确认

用户可保留图 A 的人物、图 B 的姿势，再选衣装、场景和画风；先固定关键元素，再逐项修改。每类参考应说明用途、约束强度和可能漂移部分。已完成的 2D 图只改局部时可直接重绘；大改姿势、比例或透视时再返回 3D，不要求每次重建全套模型。

卡片以名称、预览、应用/编辑/收藏为主；复杂参数在编辑器内。编号、最终卡片 UI、自动合并阈值、缓存策略、风格权重和跨模型映射仍待实现验证。

来源与权限统一遵循[AI 协作](ai-collaboration.md)。用户认可结果与实测兼容结果分别记录，不能混为“已完成”。
