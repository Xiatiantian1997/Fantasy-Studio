# 幻真画室｜图片元素拆解与保存（讨论记录）

> 2026-11-10 · 参考设计，尚未实现。基于用户提供的三张角色参考图讨论；仅保存通用设计原则，不上传原图。

## 总体原则
一组原图按八类逻辑元素整理：人物身份、体型、姿势、衣装、表情、镜头、背景、画风光影；动画为可选第九类。分类数量不等于资源卡数量：同类可保存多个镜头、服装部件等。原图只读，元素可用图片、文字/参数、遮罩和可选 3D 数据多种表示。明确区分用户确认、AI 估计与待验证。不能从单张图精确恢复被遮挡的 3D 结构。

## 已确认：元素 1｜人物身份
- **脸与发型作为整体固定保存**，包括脸部设计、刘海、侧发、后发、发色、眼睛、耳朵等固有特征。动漫人物的发型与脸是一体设计，不强制拆成独立的选择步骤。
- 人物卡默认显示完整头部而非只裁切五官；优先正面参考，能提供时补充 45°、侧面、后面。
- 应用人物身份时默认一起应用脸和发型，尽量不改动已选体型、姿势、衣装、背景和镜头。
- **允许后续修改**发型、发色、五官；改动后保存新版本，原始设计保留，不要求现在提前拆分。
- 可更换配饰（如兔耳、蝴蝶发饰）可随人物预览展示，但在底层仍作为配饰记录，不锁死为身份。
- 存储：头像/完整头部参考、特征描述与参数、来源图片引用、可信度/确认状态、可选 3D 头部。单图不能保证准确 3D 重建。

## 已确认：元素 2｜体型（简洁保存）

- **精细调整在模型编辑器内完成**：胸部形状、臀部形状、肩腰比例、腿长等可以在 3D 模型中连续微调；不要求素材库逐项展示所有高级参数。
- **保存为一个完整体型预设**：保留模型兼容标识与完整形态键/几何参数快照，以便准确恢复；但用户界面只需一张体型卡和简洁名称，不必暴露冗长参数表。
- **展示以视觉为主**：默认标准姿势、统一相机下的正面与侧面缩略图；需要时打开模型编辑器进一步微调。
- **参考来源**：保留原图关联及「AI 候选 / 用户确认」状态；不把透视夸张误认为真实体型。
- **柔软度独立**：软组织刚度、阻尼、回弹属于动画/物理材质配置，不强制绑定在体型卡里。
- **复用**：选择体型卡时应用完整体型预设，保留另一人物的脸、发型与其他独立元素；跨模型复用需适配，不承诺零误差。
- **界面原则**：快捷预设与收藏卡为主；复杂参数留在模型编辑器，不让保存流程变成填写表格。

## 已确认：3D 身材编辑入口（设计补充）

- 原有 3D 的**观察/摄影功能保留**：自由旋转、缩放、透视、镜头参数与取景；观察模式不改变人物体型。
- 新增独立的**身材编辑模式**：在同一 3D 预览窗口展开体型预设和必要的滑块，实时观察胸、腰、臀等基础轮廓变化；高级微调仍放在模型编辑器，不要求身材卡显示所有参数。
- 编辑完成后**一键保存身材卡**：底层记录完整形态键/变形参数、兼容模型标识与版本，界面展示正面/侧面缩略图与简洁名称。
- 若原始模型已有可用 Shape Keys，UI 连接较直接；若只有固定网格，需先制作或适配形态键，不能把按钮本身当作形变能力。
- 保留原有姿势/相机与体型分离的设计，避免切换身材时误改镜头。服装贴合、骨骼权重、碰撞与跨模型适配属于后续验证难点。
- **状态**：已确认产品方向，尚未修改 3D 程序或验证现有模型形态键。

## 已确认：体型参数联动、范围与修正（2026-11-10）

- 采用**一个经过验证的连续人体母版 + 三档快捷体型预设 + 连续局部微调**。不允许胸、腰、臀、四肢各自无限制独立放大，避免比例失调、接缝、关节扭曲及穿模。
- **参数关联**：改变臀部轮廓时，按规则协调腰臀过渡、骨盆附近和大腿根部；改变胸部轮廓时协调胸廓、根部、腋下及肩部连接。联动是有方向和范围的局部修正，不等于所有部位一起缩放。
- **三段有效区间**：推荐范围（已验证）、扩展范围（需提示与检测）、禁止范围（已知破面/穿模）。UI 可以显示 0–100，但底层范围必须按实际模型、形态键和体型组合实测标定，不能虚构通用数值。
- **修正机制**：主形态键 + Corrective Shape Keys（修正形态键）+ 必要的骨骼/蒙皮/碰撞修正；极端组合不保证自动完美，需允许回退或额外适配。
- **静态与动态分离**：体型卡负责几何；刚度、阻尼、软组织回弹另存为物理/动画材质参数。可提供有关联的默认值，但不得将丰满直接等同柔软。
- **保存与复用**：身材卡保存完整参数快照、母版/骨架版本和兼容信息；界面只显示名称及标准正侧面预览。跨模型复用需映射与验证。
- **验收**：至少检查三档体型与典型姿势组合下的轮廓连续性、肩胸/腰臀/大腿根部过渡、关节活动和接触穿模；未经测试的组合标为候选。
- **状态**：产品约束已确认；安全范围和联动权重仍需选定真实母版后实测，不是已实现功能。
