# 幻真画室｜软组织形变测试规范

> 2026-11-10 · 技术设计稿，尚未实现。作为 [程序化动画开发规划](animation-roadmap.md) 的独立验收专题。公开版本只讨论通用几何、材料响应与非露骨人体演示；用户私人模型和素材不得提交公开仓库。

## 一、目的与边界

建立一个可重复、可量化的 **透明刚性板按压实验**，检验角色模型的局部软组织在接触、压缩、剪切、释放与周期性运动中的形变质量。目标不是仅让模型看起来“软”，而是建立可用于不同角色、体型、部位和动画积木的**统一求解器 + 区域材料参数 + 连接约束**。

此实验是质量基准，不是从单一按压测试反推出人体全部真实力学性质的手段。优先用软球、凝胶体、面颊/腹部等中性测试模型验证，再按合法授权扩展模型。

## 二、基础装置

- **压板**：透明平板，可设宽高、厚度、法向、倾角；视觉材质不影响物理接触。
- **测试对象**：连续网格、已知尺度、局部材料区域、固定或可调边界；可选择软球/椭球、简化分层体、绑定人体模型。
- **运动控制**：位移控制优先，按毫米设置压入深度；以后可增加目标力控制。接触力必须由求解器估算或测量，不能将滑块百分比冒充牛顿。
- **观测**：压板位置、接触面积、最大凹陷、侧向鼓起、网格体积变化、恢复时间、峰值超调、穿透深度、计算耗时。
- **显示**：透视/正交相机、透明板、接触热区、变形前轮廓虚线、局部网格开关、曲线图；默认显示正常材质而非仅骨骼线。

## 三、六组标准实验

| 编号 | 实验 | 输入 | 主要观测 |
|---|---|---|---|
| P1 | 垂直准静态按压 | 压入深度 0→目标→0，低速 | 接触面积、凹陷、侧向鼓起、体积变化 |
| P2 | 斜向按压与滑动 | 板面倾角、切向位移 | 剪切形变、接触滑移、边缘异常 |
| P3 | 球形压头局部按压 | 压头半径、深度 | 局部接触分布、网格平滑性 |
| P4 | 快速卸载 | 初始压缩、释放时间 | 恢复时间、超调、阻尼、数值稳定 |
| P5 | 周期性驱动 | 频率、幅度、循环次数 | 相位延迟、响应幅度、共振与稳定性 |

可增加 P7：相同归一化按压在不同体型/尺度模型上的对比。不同尺寸不应直接沿用所有刚度和阻尼数值而不校验。


### P6｜圆柱压头按压（新增）

在原有平板与球形压头之外，增加**短圆柱压头**，用于观察窄接触区域的局部凹陷、边缘鼓起、接触压力集中与释放回弹。它是中性的通用软材料实验，不涉及特定身体部位。

- **压头几何**：圆柱半径、长度、端面圆角半径、朝向；允许切换「平端面向下」与「圆柱侧面向下」两种接触方式，避免把两者误当成同一种接触。
- **运动**：沿表面法线逐步压入、保持、释放；可选倾斜与横向移动。默认采用位移控制，记录真实单位 mm 与速度 mm/s。
- **对照**：在相同压入深度下，与平板、球形压头比较接触面积、凹陷曲线、侧向隆起、接触边缘平滑度及回弹时间。由于接触面积不同，不能直接把同一压入深度等同于同一压力。
- **数值约束**：圆柱端面边缘应适当倒圆，避免数学尖角造成局部应力奇异和网格伪影；记录网格密度与最大穿透量。
- **界面**：压头类型切换、直径、长度、圆角、压入深度、方向、释放速度；显示接触区域与原始轮廓叠影。
- **验收**：圆柱侧面接触应呈条状分布，端面接触应呈近圆形分布；接触区无明显破面、穿透或抖动；释放后形状可稳定恢复。

**实施顺序**：在静态平板按压 P1 和球形压头 P3 的接触验证后加入 P6，复用同一碰撞/材料求解器，不另造独立动画系统。性能与材料真实性仍需实测。

## 四、数学模型与实现层级

### 4.1 低成本视觉原型

使用骨骼、局部 Shape Keys、权重场与解析形变函数实现压缩和侧向补偿。先确保模型连续、交互明显、接触边界无硬折线。这一层只验证视觉几何，**不能宣称具有真实材料力学**。

### 4.2 动态响应

以质量-弹簧-阻尼为最小模型：

```text
m * x''(t) + c * x'(t) + k * x(t) = F(t)
```

分别控制有效质量 m、阻尼 c、刚度 k、外部驱动 F。区分驱动位移和外力；记录固定时间步长、积分方法及稳定性。此式适合局部次级运动，不等于完整软组织连续体模型。

### 4.3 高质量可选层

必要时研究位置约束动力学（PBD/XPBD）、体积约束、有限元（FEM）或预计算形变缓存。优先以**实际可用的交互帧率**为目标，不在第一版强行引入高成本求解器。真实人体材料还涉及非线性、黏弹性、组织分层、各向异性和附着边界；需要实验数据才能标定，不能从外观猜出真实参数。

### 4.4 体积与接触

对近似不可压缩区域，约束局部体积变化在合理范围；简单椭球压缩时，若一个轴缩放为 `1-a`，其他两个轴可用 `1/sqrt(1-a)` 作初步体积补偿，但不应把这种全局缩放直接用于复杂人体接触。接触约束需防止压板穿透，且不得用无限刚度造成数值爆炸。

## 五、交互界面（手机优先）

主界面只保留：**测试对象、压板位置/角度、压入深度、材料预设、播放/释放、重置、对比、导出**。

高级面板：刚度、阻尼、质量/惯性、网格密度、求解步长、体积约束、接触摩擦、固定边界。显示单位与默认值，明确哪些是可测物理量、哪些只是视觉调参。

推荐默认从软球开始：压入 0 mm；低/中/高三种材料预设；正交侧视；显示压板、原始轮廓和当前网格。所有预设可连续微调。

## 六、数据结构建议

```json
{
  "schema_version": "0.1",
  "test_id": "P1",
  "object_id": "soft_ellipsoid_01",
  "scale_unit": "m",
  "tool": {"type": "plane", "size": [0.25, 0.25], "tilt_deg": 0},
  "drive": {"mode": "displacement", "depth_m": 0.012, "duration_s": 2.0},
  "material": {"preset": "medium", "stiffness": 1.0, "damping": 0.6},
  "solver": {"name": "visual_proxy", "fixed_dt_s": 0.0166667},
  "metrics": ["contact_area", "indentation", "lateral_displacement", "volume_error", "recovery_time", "penetration"]
}
```

上述 stiffness/damping 为**无量纲视觉预设值**，不能误写成真实材料单位。真正物理求解器必须定义材料参数单位、模型离散方式及求解方法。与 3D 仓库的角色坐标、骨架和模型接口对齐后再固定 schema。

## 七、分阶段实施

**A｜静态几何实验**：软球/椭球 + 透明平板 + 压入滑块，保证接触位置和侧向形变明显；可自由旋转查看，模型不破面。

**B｜释放与回弹**：增加速度、阻尼和固定时间步长，展示快慢释放和恢复曲线；相同参数重复播放结果一致。

**C｜接触与材料**：加入球形压头、斜向滑动、接触/穿透检测、局部体积指标；提供三档材料预设。

**D｜角色适配**：将求解器接入一个有授权的成年人体模型的中性测试区域，验证不同体型和边界约束；保留区域权重与模型适配配置。

**E｜动画系统集成**：按压结果与动作积木的次级响应共用参数与求解接口；记录导出 30/60 FPS 的 MP4，避免低帧 GIF 被误认为原始动画。

## 八、验收标准

- 形变连续，无明显网格破洞、三角形翻面、尖锐折痕。
- 压板与对象接触关系可信；穿透量可记录且受控。
- 卸载后可恢复至基准形态；残余误差可量化。
- 不同材料预设的响应有明确可见差异，且变化方向合理。
- 速度和帧率变化不导致明显数值发散；导出结果与预览一致。
- 记录每帧计算耗时与实际 FPS；目标为单模型流畅交互，具体性能需在 RTX 3060 Ti 上实测。
- 同一测试可保存配置、复现并导出对比视频与测量 CSV。
- **禁止以单个“柔软度”数值替代全部刚度、阻尼、附着和几何信息；禁止把未经标定的视觉模拟称作真实人体物理。**

## 九、与幻真画室的关系

- 主仓库：UI、实验配方、素材索引、质量报告。
- 3D 仓库：网格、骨架、材料区域、接触求解器、实时预览与 Blender 适配。
- 2D 仓库：可选将可靠的 3D 形变参考用于分层网格动画，但不能由单张图片恢复真实 3D 物理。
- 私人素材不进入公开仓库；本规范仅保存中性技术和测试数据。

**开发优先级**：这是动画系统的验证工具，不取代当前优先的 2D 出图与 3D 姿势/相机最小闭环。完成 A/B 两阶段后再决定是否值得开发更复杂的软体物理。
